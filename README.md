# 🍱 모란역 9,000원 점심 로드 (Moran Lunch Map)

모란역 인근에서 점심 예산 **9,000원 한도** 내에서 알차게 즐길 수 있는 식당을 발굴하고, 실제 현장 가격 변동을 쉽게 확인 및 업데이트할 수 있는 프론트엔드 웹 애플리케이션입니다.

---

## 🚀 빠른 시작

```bash
# 1. 프로젝트 폴더 이동
cd moran-lunch-map

# 2. 의존성 설치 (이미 완료됨)
npm install

# 3. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

---

## 🌟 핵심 기능

1. **9,000원 타겟 필터 & 슬라이더**
   - 9,000원 이하 메뉴를 보유한 모란역 식당만 골라서 확인 가능
   - 필요 시 예산 슬라이더(5,000원 ~ 12,000원)로 유연하게 필터링

2. **실제 가격 DB 업데이트 (현장 검증 반영)**
   - 포털 사이트 정보와 실제 현장 가격이 다를 때, 즉시 가격 수정 및 신규 메뉴 추가
   - 브라우저 로컬 DB(LocalStorage)에 영구 저장되며, 가격 변동 히스토리 로그 기록

3. **네이버 지도 API & 모란역 인터랙티브 맵 듀얼 모드**
   - **NCP Client ID 입력 시**: 실제 네이버 고화질 지도 타일 및 마커로 즉시 연동
   - **API 키 미등록 상태**: 별도 발급 없이도 모란역 실제 위/경도 기반 인터랙티브 가상 맵으로 즉시 작동

4. **직장인 동료와 데이터 공유 (JSON Export/Import)**
   - 내가 모란역에서 발굴한 알짜 9,000원 식당 목록을 JSON 파일로 클릭 한 번에 다운로드
   - 팀원의 웹페이지에서 해당 JSON을 불러와 동기화 가능

5. **"오늘 뭐 먹지?" 점심 룰렛**
   - 결정 장애를 해결해 주는 9천원 예산 통과 식당 랜덤 추첨 & 컨페티 효과

6. **새 식당 추가 및 삭제**
   - 모란역 부근에 새로 생긴 가성비 밥집을 직접 등록 가능
